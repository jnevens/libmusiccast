# YXC API specifications (local copies)

Official **Yamaha Extended Control (YXC)** PDFs are **not** shipped in this
git repository (copyright and redistribution restrictions).

If you maintain a local reference copy for development, place files such as:

- `YXC_API_Spec_Basic_v2.0.pdf`
- `YXC_API_Spec_Advanced_v2.0.pdf`

in this `docs/` directory. They are listed in `.gitignore` and will not be
committed.

Implementation coverage vs the Basic and Advanced specs is tracked in
[mcctl-api-coverage.md](mcctl-api-coverage.md).
